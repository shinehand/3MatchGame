# Zoo-Zoo Pop UI 아트 스펙

## 아트 목표

`Zoo-Zoo Pop`의 UI는 업무용 카드 UI가 아니라 밝은 모바일 퍼즐 게임 UI여야 한다. 모든 패널, 버튼, HUD는 동물 캔디 블록과 구조 모험이라는 테마를 직접 드러낸다.

## 비주얼 키워드

- 동물 캔디
- 반짝이는 구조 모험
- 부드러운 젤리 버튼
- 둥근 과자 프레임
- 깊이감 있는 보드
- 짧고 선명한 피드백

## 금지 스타일

- 흰색/회색 카드가 줄지어 있는 관리 도구형 레이아웃.
- 설명문 중심 화면.
- 보드보다 사이드바가 더 강한 화면.
- 같은 색 계열만 반복되는 단조로운 팔레트.
- 사각형 버튼에 긴 텍스트를 계속 넣는 방식.
- 결과 화면을 텍스트 보고서처럼 구성하는 방식.

## 컬러 시스템

- Sky Blue: `#6EC6FF`, 배경과 맑은 공기감.
- Candy Pink: `#FF74A8`, 주요 강조와 성공 리액션.
- Lemon Yellow: `#FFD85A`, 별, 보상, 현재 진행 강조.
- Leaf Green: `#58C878`, 구조/회복/목표 완료.
- Berry Purple: `#7A55FF`, 특수 블록과 콤보.
- Cocoa Text: `#513D30`, 본문 텍스트.
- Deep Navy: `#213A55`, 강한 제목과 HUD 대비.

## 타이포그래피

- 제목: 굵고 둥근 폰트 감성. 34~56px.
- HUD 숫자: 두껍고 즉시 읽히는 숫자. 28~40px.
- 팝업 본문: 20~26px.
- 버튼: 짧은 명령형. 24~32px.
- 모바일에서 긴 한국어 문장은 두 줄까지 허용하되 버튼 안에서는 한 단어 또는 아이콘 중심을 우선한다.

## 공통 컴포넌트

### Primary Button

- 형태: 젤리 캡슐.
- 컬러: Lemon Yellow 바탕, 오렌지 계열 그림자.
- 상태: 기본, 눌림, 비활성, 주목 펄스.
- 텍스트: `PLAY`, `START`, `다음`.

### Secondary Button

- 형태: 작고 둥근 아이콘 버튼.
- 컬러: 밝은 파란색 또는 흰색 반투명 젤리.
- 용도: 홈, 재시작, 일시정지, 설정.

### Stage Node

- 현재 스테이지: 큰 발바닥 링, 황금 테두리, 미세한 스케일 펄스.
- 클리어 스테이지: 별 개수 표시, 작은 반짝임.
- 잠긴 스테이지: 흐린 유리 캡슐과 자물쇠.

### Goal Chip

- 구조 대상 동물 얼굴 40~56px.
- 진행률 `현재/목표`.
- 완료 시 초록 체크 배지와 작은 링 애니메이션.

### Board Frame

- 보드는 게임의 제단처럼 보인다.
- 바탕은 진한 블루/퍼플 계열이 아니라 하늘/젤리/과자 프레임 조합.
- 내부 비활성 칸은 흐린 유리 슬롯으로 표시한다.
- 프레임 위쪽에는 약한 광택 밴드.

## 화면별 아트 스펙

### Loading

- 로고와 블록 낙하 미니 쇼.
- 배경은 실제 월드맵의 일부를 흐리게 보여준다.
- 로딩 바는 발바닥 트랙 형태.

### Home

- 첫 뷰의 50% 이상은 로고, 마스코트, PLAY 버튼.
- 동물 블록 10종 중 5종 이상이 장식 또는 프리뷰로 보인다.
- `랭킹`, `컬렉션`, `설정`은 하단 아이콘 버튼.

### World Map

- 세로 스크롤 배경. 10스테이지마다 숲, 정원, 밤하늘, 피날레 테마.
- 스테이지 경로는 점선이 아니라 사탕 리본/발자국으로 연결.
- 현재 노드는 가장 크고 밝게.

### Stage Popup

- 팝업 프레임은 과자/젤리 소재.
- 목표는 카드가 아니라 큰 아이콘 칩.
- 부스터 슬롯은 3개를 하단에 고정.
- 시작 버튼은 하단 전체 폭의 가장 강한 요소.

### Gameplay

- 세로 모드에서 상단 HUD는 압축한다.
- 보드는 화면 중앙에서 가장 큰 면적을 차지한다.
- 목표 요약은 보드 위 또는 바로 아래에 칩 1줄로 둔다.
- 버튼은 아이콘 중심으로 배치한다.
- 사이드바가 있을 경우 한 덩어리 HUD 패널로 정리한다.

### Result

- Victory: 별 3개, 구조 마스코트, 보상 아이콘, 다음 버튼.
- Failure: 남은 목표, 추천 부스터, 재도전 버튼.
- 두 화면 모두 긴 본문 대신 3개 이하의 정보 블록으로 구성한다.

## 아이콘 규칙

- 홈: 집 아이콘.
- 재시작: 회전 화살표.
- 일시정지: 두 줄 아이콘.
- 다음: 삼각형 또는 오른쪽 화살표.
- 랭킹: 왕관.
- 설정: 톱니.
- 하트/골드/부스터는 텍스트보다 아이콘을 먼저 보이게 한다.

## 승인 기준

- 스크린샷만 보고 퍼즐 게임으로 인지된다.
- 홈 화면에 개발 설명문이 보이지 않는다.
- 게임 화면에서 보드가 가장 큰 시각적 무게를 가진다.
- 주요 버튼은 손가락으로 누르기 쉬운 크기다.
- 결과 화면의 감정이 성공/실패로 즉시 구분된다.
