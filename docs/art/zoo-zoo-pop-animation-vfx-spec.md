# Zoo-Zoo Pop 애니메이션/VFX 스펙

## 목표

현재 구현의 가장 큰 문제는 이펙트가 타일 내부에 갇히거나 거의 보이지 않아 화면 전체가 살아 움직이지 않는다는 점이다. 모든 주요 이벤트는 `VFXLayer`에서 보드와 HUD 위에 재생되어야 한다.

## 레이어 구조

1. BackgroundLayer
2. BoardFrameLayer
3. BlockLayer
4. BlockOverlayLayer
5. VFXLayer
6. ComboTextLayer
7. ZooZooTimeLayer
8. ResultLayer
9. UILayer

Godot 구현에서는 `FxLayer`를 별도 `CanvasLayer`로 두고, 하위에 `BoardFxRoot`, `HudFxRoot`, `ScreenFxRoot`를 둔다.

## 성능 원칙

- 1회 매치에서 동시에 12개 이상의 파티클성 노드가 생기면 표시 수를 제한한다.
- 모바일 기준 VFX 노드는 재사용 풀을 우선한다.
- 텍스처는 512px 이하의 투명 PNG 또는 SVG 기반 아틀라스를 사용한다.
- 화면 전체 플래시는 0.18초 이하로 짧게.
- 입력 잠금은 실제 보드 처리보다 길어지지 않는다.

## 블록 애니메이션

### Idle

- 4~6초마다 랜덤 블록 1~2개만 약하게 반짝인다.
- 모든 블록이 동시에 움직이는 효과는 피한다.

### Selected

- 선택 링이 0.12초 안에 나타난다.
- 선택 블록은 1.06배 커진다.
- 다른 블록은 어두워지지 않는다.

### Match

- 타일 내부에서는 블록이 0.86배로 줄어든 뒤 사라진다.
- VFXLayer에서는 해당 위치에 별/캔디 파편 또는 동물별 색 파동을 표시한다.
- 콤보가 2 이상이면 화면 상단에 `Combo xN` 배너를 재생한다.

### Fall

- 새로 생성된 블록은 위에서 떨어진 것처럼 보인다.
- 거리 1칸마다 0.025초 지연.
- 착지 시 1.06배 수직 스쿼시 후 복귀.

## 특수 블록 VFX

### Row

- 생성: 가로 줄무늬 배지가 우상단에서 팝.
- 발동: 해당 행에 좌우 빛줄기 2개가 0.22초 동안 지나간다.

### Column

- 생성: 세로 줄무늬 배지가 우상단에서 팝.
- 발동: 해당 열에 상하 빛줄기 2개가 0.22초 동안 지나간다.

### Bomb

- 생성: 둥근 충격파와 짧은 흔들림.
- 발동: 3x3 범위에 원형 파동, 중심에서 바깥으로 파편.

### Rainbow

- 생성: 무지개 링 2회 확장.
- 발동: 대상 동물들에게 짧은 연결선과 순차 팝.
- 화면 전체 플래시는 알파 0.22 이하.

## 목표 완료 VFX

- 목표 달성 순간 사운드와 함께 목표 칩 위에 초록 링.
- 화면 중앙 또는 목표 칩 근처에 `구출!` 또는 `목표 완료!` 텍스트.
- 완료된 목표는 계속 밝게 두고, 미완료 목표는 그대로 유지한다.

## 이동 수 경고

- 5회 이하: 이동 수 HUD가 주황색으로 펄스.
- 3회 이하: 붉은 펄스와 짧은 화면 상단 경고.
- 매번 `_update_hud`가 호출될 때 반복하지 않고 남은 이동 수가 바뀔 때 1회만 재생한다.

## Zoo-Zoo Time VFX

- 배경 알파 0.35 어둡게.
- 중앙 상단 `Zoo-Zoo Time!`.
- 남은 이동 수가 하나씩 보드로 날아가며 특수 블록 생성.
- 특수 블록 발동은 0.18초 간격으로 순차 처리.

## Result VFX

### Victory

- 결과 팝업 표시 전 화면 중앙에서 별 3개 자리가 먼저 보인다.
- 획득한 별만 순차 팝.
- 보상 아이콘은 팝업 안으로 튀어 오른다.

### Failure

- 화면 전체는 어둡게, 목표 칩은 밝게.
- `조금만 더!` 텍스트가 작게 튀어나온다.
- 남은 목표 1~3개가 순차 표시된다.

## 개발 연결 API

- `play_match_burst_at(position, combo)`
- `play_special_created(position, special_type)`
- `play_combo_banner(combo)`
- `play_goal_rescue(position, label)`
- `play_last_moves_warning(moves)`
- `play_star_reveal(star_count)`
- `play_rainbow_clear(positions)`

모든 API는 보드 로직을 막지 않는 짧은 비동기 연출이어야 한다.
