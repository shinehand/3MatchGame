# Project Animal Match Master Development Plan

## 1. 목표

Godot 4.x 기반의 글로벌 모바일 매치3 게임을 소프트 런칭 가능한 품질까지 끌어올리고, 지표 검증 후 글로벌 런칭으로 확장한다.

## 2. 단계별 로드맵

| 단계 | 기간 기준 | 목표 | 게이트 |
| --- | --- | --- | --- |
| Prototype | T+0-4주 | 코어 보드, 스와이프, 매치, 낙하, 리필, 10개 테스트 레벨 | 3분 플레이 루프가 끊기지 않음 |
| MVP Development | T+5-14주 | 100레벨, 특수 블록, 기본 UI, 튜토리얼, 부스터, 저장, 사운드/VFX | 내부 QA에서 주요 플로우 통과 |
| Soft Launch | T+15-22주 | 분석 SDK, 원격 설정, IAP/광고, 현지화 1차, 제한 국가 출시 | D1/D7 유지율과 결제/광고 지표 확보 |
| Global Launch | T+23-30주 | 글로벌 스토어 등록, 마케팅 자산, 안정화, 라이브 운영 체계 | crash-free 99% 이상, 스토어 심사 통과 |

## 3. WBS

### 3.1 기획

- 코어 루프와 특수 블록 규칙 확정
- 1-100레벨 난이도 밴드 설계
- 초반 튜토리얼과 실패 후 재도전 UX 설계
- 부스터, 하트, 광고, 시즌 이벤트 규칙 정의
- 소프트 런칭 지표 기준 정의

### 3.2 아트

- 동물 12종 기본 블록과 공통 표정 상태 제작
- blink, smile, match, fever, worried 표정 프레임 제작 및 atlas 정리
- 특수 블록 배지, 피버 UI, 목표 칩 제작
- 홈, 스테이지 선택, 게임 플레이, 결과 팝업 UI 정리
- 스프라이트 아틀라스와 해상도별 export 규칙 정리
- 스토어 아이콘, 스크린샷, 피처 그래픽 준비

### 3.3 개발

- 보드/셀/블록 데이터 구조 구현
- 매치 판정, 특수 블록 생성/발동, 낙하/리필/셔플 구현
- 레벨 JSON 로더와 검증 스크립트 유지
- UI/HUD, 저장, 튜토리얼, 설정 구현
- IAP, 광고, 분석 SDK, 원격 설정 연동
- Android/iOS 빌드와 export preset 관리

### 3.4 QA

- 핵심 플로우 테스트: 설치, 첫 실행, 튜토리얼, 10레벨 진행
- 레벨 QA: 목표 달성 가능성, 실패율, 막힘 상태, 셔플 검증
- 기기 QA: 저사양 Android, 기준 iPhone, 태블릿 비율
- 수익화 QA: 구매 복구, 광고 보상, 네트워크 실패, 하트 회복
- 회귀 QA: 빌드별 주요 씬 진입과 저장 호환성

## 4. 리스크 관리

| 리스크 | 징후 | 대응 |
| --- | --- | --- |
| 보드 연쇄 중 프레임 드랍 | 콤보 4단 이상에서 입력 지연 | Tween 큐 제한, 파티클 풀링, 동시 VFX 수 제한 |
| 저사양 기기 메모리 증가 | 스테이지 반복 후 앱 종료 | 텍스처 아틀라스, 오브젝트 풀, 씬 전환 시 참조 해제 |
| 레벨 데이터 오류 | 불가능한 목표 또는 막힌 보드 | JSON validator와 자동 샘플 플레이 검증 |
| 수익화 UX 반감 | 실패 후 이탈 증가 | 광고/결제 노출 빈도 원격 설정화 |
| iOS/Android 정책 차이 | 심사 반려 또는 SDK 오류 | 스토어별 체크리스트와 빌드 분기 관리 |
| 현지화 품질 저하 | UI 잘림, 오역 리뷰 | 문자열 키 기반 관리, pseudo-localization QA |

## 5. 런칭 준비 리스트

### Android

- Google Play Console 앱 생성
- 패키지명, 서명 키, 버전 코드 정책 확정
- AAB export preset 검증
- 개인정보 처리방침 URL 등록
- 데이터 보안 섹션 작성
- 내부 테스트 트랙, 비공개 테스트, 국가 제한 소프트 런칭 설정

### iOS

- Apple Developer 계정 및 bundle id 준비
- App Store Connect 앱 생성
- provisioning, certificate, TestFlight 빌드 검증
- ATT/IDFA 사용 여부와 문구 확정
- IAP 상품, 구매 복구, 영수증 검증 테스트

### 현지화

- 1차 언어: 영어, 한국어, 일본어
- 2차 후보: 스페인어, 포르투갈어, 독일어, 프랑스어
- 문자열 키, UI 길이 제한, 숫자/통화 표기 규칙 분리

### 마케팅 자산

- 앱 아이콘 1024x1024
- 스토어 스크린샷: 홈, 플레이, 피버, 보상, 이벤트
- 15초/30초 짧은 플레이 영상
- 소프트 런칭용 광고 소재 3종
- 글로벌 런칭용 키아트와 캐릭터 소개 이미지

## 6. 소프트 런칭 성공 기준

- D1 retention: 35% 이상
- D7 retention: 12% 이상
- 평균 세션 길이: 5분 이상
- Level 1-10 이탈률: 20% 이하
- crash-free sessions: 99% 이상
- rewarded ad opt-in: 실패 후 제안 기준 20% 이상
