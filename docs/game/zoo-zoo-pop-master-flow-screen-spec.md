# Zoo-Zoo Pop 마스터 플로우/화면 기획서

## 목표

현재 버전은 매치3 규칙은 있으나 첫 인상이 게임보다 개발용 UI에 가깝다. `Zoo-Zoo Pop`은 밝은 동물 캔디 블록을 터뜨리고 구조 목표를 달성하는 모바일 캐주얼 3매치로 재정의한다. 모든 화면은 플레이어가 "어디에 있는지", "무엇을 해야 하는지", "무슨 보상을 얻는지"를 즉시 알게 해야 한다.

## 핵심 경험

- 3초 안에 게임명, 동물 캔디 블록, 시작 행동이 보인다.
- 한 번의 매치에도 팝, 점수, 수집, 콤보 피드백이 동시에 돌아온다.
- 특수 블록과 콤보 게이지는 보드 안에 갇히지 않고 화면 상위 레이어에서 축하받는다.
- 결과 화면은 보고서가 아니라 성공/실패/보상/다음 행동을 보여주는 게임 팝업이다.
- 화면 전환은 `로딩 -> 홈 -> 월드맵 -> 스테이지 팝업 -> 게임 -> 결과 -> 다음 행동`으로 고정한다.

## Loading Screen

### 목적

게임 진입 전 브랜드와 기대감을 만든다. 단순 진행률 막대가 아니라 동물 캔디 블록이 떨어지고 튀는 짧은 쇼케이스로 구성한다.

### 레이아웃

- 배경: 밝은 하늘, 둥근 구름, 작은 구조 섬루엣.
- 중앙 상단: `Zoo-Zoo Pop` 로고. 첫 로딩 때 0.3초 뒤 팝 스케일.
- 중앙: 토끼, 고양이, 병아리 블록이 3개 순서로 떨어져 한 줄 매치를 만드는 미니 애니메이션.
- 하단: 로딩 바. 바 내부는 사탕 줄무늬 또는 발바닥 패턴.
- 하단 보조 문구: 짧은 팁 1줄. 예: "4개를 맞추면 줄무늬 동물이 탄생합니다."

### 상태

- 최초 로딩: 로고 팝, 블록 낙하, 로딩 바 0~100%.
- 빠른 로딩: 최소 1.2초 유지 후 홈으로 전환.
- 에러: 재시도 버튼과 네트워크/리소스 에러 메시지.

## Home Screen

### 목적

게임의 브랜드, 장르, 대표 동물을 즉시 보여주고 플레이 시작을 유도한다.

### 레이아웃

- 상단 15%: 재화, 하트, 설정 아이콘. 텍스트 버튼 대신 아이콘 중심.
- 중앙 45%: 큰 로고와 동물 마스코트 2~3마리. 배경은 실제 게임 월드 일부가 보여야 한다.
- 중앙 하단: 가장 큰 `PLAY` 버튼. 버튼은 사탕 캡슐형, 눌렀을 때 0.94배 스케일.
- 하단 25%: 랭킹, 이벤트, 컬렉션, 설정 진입 버튼.
- 첫 화면에서 보드 카드나 개발용 설명문은 금지한다.

### 필수 피드백

- PLAY 버튼은 대기 중 2.5초마다 부드러운 펄스.
- 동물 마스코트는 3~5초마다 표정/귀/눈 깜빡임.
- 랭킹 버튼은 기록이 있을 때 작은 왕관 배지 표시.

## World Map

### 목적

스테이지를 목록이 아니라 모험 경로로 보여준다.

### 레이아웃

- 세로 스크롤 맵. 10개 단위로 테마가 바뀐다.
- 스테이지 노드는 발바닥, 별, 동물 집 모양을 섞어 사용한다.
- 클리어 노드: 별 개수와 완료 반짝임.
- 현재 노드: 가장 크고 밝은 링, 마스코트가 옆에서 손짓.
- 잠김 노드: 회색 자물쇠가 아니라 흐린 유리 캡슐.
- 상단 고정바: 홈, 하트, 골드, 설정.

### 상호작용

- 현재 스테이지 탭: Stage Popup 표시.
- 클리어 스테이지 탭: 재도전 팝업.
- 잠긴 스테이지 탭: 해금 조건 팝업.
- 스크롤 정지 후 현재 노드가 화면 중앙에 자동 정렬.

## Stage Popup

### 목적

시작 전 목표, 이동 수, 보상, 부스터를 확인시킨다.

### 레이아웃

- 상단: 스테이지 번호와 이름. 예: `Level 7 · Rainbow Trail`.
- 중앙: 목표 2~3개를 큰 아이콘 칩으로 표시.
- 중앙 하단: 이동 수, 난이도, 추천 특수 블록.
- 하단: Pre-Booster 3칸.
  - 무지개 발바닥
  - 줄무늬 동물
  - 폭탄 동물
- 최하단: `START` 버튼. 하트 소모가 있으면 버튼 근처에 표시.

### 상태

- 부스터 선택 가능: 칸이 밝고 수량 배지 표시.
- 부스터 부족: 잠김이 아니라 상점/획득 안내 버튼.
- 하트 부족: 시작 버튼 대신 충전 팝업.

## Gameplay Screen

### 목적

보드가 주인공이어야 한다. HUD는 목표와 이동 수만 빠르게 보여주고, 이펙트는 보드 위와 화면 위를 가로지른다.

### 세로 레이아웃

- 상단 12%: 레벨, 이동 수, 점수, 일시정지.
- 상단 보조 12%: 목표 요약 칩. 수집 대상은 동물 얼굴과 진행률로 표시.
- 중앙 58~64%: 8x8 보드. 배경 패널은 깊이감 있는 게임 프레임.
- 하단 10%: 재시작, 일시정지, 홈 또는 부스터 슬롯.
- VFX Layer: 보드 위, HUD 위에 독립적으로 재생된다.

### 가로 레이아웃

- 좌측/중앙: 보드 70%.
- 우측: 목표, 이동 수, 콤보 게이지, 버튼.
- 우측 패널은 카드 묶음처럼 보이지 않게 하나의 게임 HUD 패널로 통합한다.

### HUD 우선순위

1. 남은 이동 수
2. 현재 목표와 남은 수량
3. 콤보 게이지
4. 점수
5. 일시정지/홈/재시작

### 보드 규칙

- 비활성 칸도 완전 투명 금지. 흐린 슬롯이나 구멍이 보여야 보드 형태를 읽을 수 있다.
- 장애물은 동물 얼굴을 완전히 가리지 않는다. 가장자리 덩굴/덤불처럼 겹친다.
- 특수 배지는 우상단 30% 크기 안에서 고정한다.
- 선택, 스왑, 매치, 낙하, 리필은 모두 0.1~0.35초 안에 피드백이 있어야 한다.

## Block States

- Idle: 아주 약한 광택 이동 또는 호흡감.
- Hover/Touch: 선택 링, 1.06배 스케일.
- Swap Commit: 두 블록이 서로 밀고 들어가는 이동.
- Invalid: 좌우 흔들림과 먼지 퍼프.
- Matched: 블록 내부 팝과 VFX Layer의 별/잎/캔디 파편.
- Special Created: 해당 칸 위에서 배지 링과 짧은 축하 텍스트.
- Falling: 거리별 지연을 둔 낙하와 착지 스쿼시.
- Obstacle Damaged: 덤불 조각이 보드 위로 튀고 사라짐.

## Special Blocks

- Row: 가로 줄무늬 배지. 발동 시 좌우로 빛 줄기가 지나간다.
- Column: 세로 줄무늬 배지. 발동 시 상하로 빛 줄기가 지나간다.
- Bomb: 중심에서 원형 충격파.
- Rainbow: 무지개 구슬. 대상 동물과 연결선이 뻗고 동일 동물이 순차 팝.

## Combo Gauge

- 매치가 발생하면 최소 1칸 충전.
- 콤보와 특수 생성은 추가 충전.
- 최대치 도달 시 `Zoo-Zoo Charge!` 배너와 함께 일반 블록 3개를 특수 블록으로 변환.
- 게이지 보상은 플레이어가 무슨 일이 일어났는지 알 수 있게 상단 배너와 보드 링을 동시에 사용한다.

## Zoo-Zoo Time

### 발동 조건

스테이지 클리어 후 남은 이동 수가 1 이상이면 결과 팝업 전에 발동한다.

### 플로우

1. 보드 입력 잠금.
2. 남은 이동 수 카운터가 1씩 감소.
3. 이동 수 1개당 랜덤 블록 1개를 특수 블록으로 변환.
4. 변환된 특수 블록이 순차 발동.
5. 추가 점수 정산.
6. Victory Result로 전환.

### 연출

- 화면 중앙 상단에 `Zoo-Zoo Time!`.
- 배경은 살짝 어두워지고 보드 위 특수 블록만 밝게 유지.
- 보너스 점수는 우상단 점수 HUD로 빨려 들어간다.

## Victory Result

### 목적

성공 감정, 보상, 다음 행동을 빠르게 제공한다.

### 레이아웃

- 상단: 스테이지 클리어 타이틀.
- 중앙: 별 1~3개가 순차로 튀어나온다.
- 중앙 하단: 구조된 동물 또는 마스코트 리액션.
- 보상 영역: 골드, 아이템, 랭킹 점수.
- 버튼: `다음`, `지도`, `다시`.

### 정보 우선순위

1. 클리어 여부
2. 별 개수
3. 보상
4. 다음 행동
5. 세부 목표 결과

## Failure Result

### 목적

실패를 처벌이 아니라 재도전 동기로 만든다.

### 레이아웃

- 상단: `조금만 더!`
- 중앙: 남은 목표를 1~3개로 요약.
- 보조: 추천 부스터 또는 가장 가까웠던 목표.
- 버튼: `재도전`, `지도`, `부스터 받기`.

### 금지

- 긴 텍스트 리포트 금지.
- 실패 화면에서 점수와 내부 로그를 최상단에 두지 않는다.

## Meta/Economy

### MVP

- 스테이지 1~10
- 별 1~3개
- 로컬 최고 점수
- 랭킹 버튼은 로컬 랭킹 요약
- 부스터는 UI 슬롯만 먼저 준비

### 상용 확장

- 하트
- 골드
- 일일 보상
- 이벤트 맵
- 친구 랭킹
- 실패 후 추가 이동 구매

## QA 승인 기준

- 로딩, 홈, 맵, 스테이지 팝업, 게임, 결과의 목적이 캡처만 보고도 구분된다.
- 보드가 첫 화면의 주인공으로 보인다.
- 매치/특수/콤보/결과 연출이 타일 내부에만 머물지 않는다.
- 세로 390x844, 430x932, 가로 1280x720, 데스크톱 1440x900에서 텍스트 겹침이 없다.
- 버튼은 한 화면에서 기본 행동이 가장 크게 보인다.
- 유저가 첫 스테이지 시작까지 2번 이하의 탭으로 진입 가능하다.
