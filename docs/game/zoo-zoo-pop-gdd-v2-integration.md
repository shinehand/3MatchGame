# Zoo-Zoo Pop GDD v2.0 통합 노트

원본 기획: `/Users/shinehandmac/Downloads/Zoo_Zoo_Pop_Detailed_GDD.md`

## 통합 방향

- 프로젝트 명칭은 `Zoo-Zoo Pop`을 기준으로 정리한다.
- 기존 구조 판타지는 유지하되, 표현은 `동물 캔디 블록을 터뜨리는 밝은 캐주얼 3매치`로 전면에 둔다.
- GDD v2.0의 10종 동물, 무지개 구슬, Combo Gauge, 랭킹, 결과 보상 흐름을 현 구현에 단계적으로 흡수한다.

## 이번 개발 반영 범위

- 기본 동물 풀을 5종에서 10종으로 확장한다.
  - 토끼, 곰, 고양이, 병아리, 개구리
  - 강아지, 판다, 돼지, 펭귄, 여우
- 홈 화면 브랜드를 `Zoo-Zoo Pop`으로 변경하고 10종 동물 프리뷰를 노출한다.
- 홈 화면 보조 버튼에 `랭킹`을 추가하고 로컬 기록 요약을 표시한다.
- 5개 일직선 매치는 `무지개 구슬`을 생성한다.
- L/T자 교차 매치는 `폭탄 동물`을 생성한다.
- Combo Gauge를 HUD에 추가한다.
- Combo Gauge가 가득 차면 일반 블록 3개를 특수 블록으로 변환한다.
- Stage 7-10에 신규 동물이 낮은 확률로 등장하도록 데이터 파일을 확장한다.
- Home을 `PLAY` 중심의 게임 타이틀 화면으로 재구성한다.
- World Map/Stage Select에서 Stage Popup을 띄운다.
- Pre-Booster 3종을 선택하고 게임 시작 보드에 반영한다.
- Zoo-Zoo Time으로 남은 이동 수를 보너스 특수 폭발로 정산한다.
- Reward UI에 별, 골드, Zoo-Zoo Time 보너스를 표시한다.
- `FxLayer`로 매치/특수/콤보/목표/결과 별 연출을 상위 레이어에서 재생한다.

## 다음 개발 범위

- Splash Screen: `Zoo-Zoo Pop` 로고 애니메이션.
- 신규 장애물: 잠든 고양이, 사료통, 덩굴.
- 10종 동물별 매칭 표정/자막/효과음 차별화.

## 개발 주의

- Candy Crush Saga의 고유 캐릭터, 맵, UI 트레이드 드레스는 복제하지 않는다.
- 레퍼런스는 `밝고 상업적인 모바일 3매치 문법`까지만 차용하고, 동물 캔디 블록과 구조 캠페인을 Zoo-Zoo Pop의 고유 축으로 삼는다.
