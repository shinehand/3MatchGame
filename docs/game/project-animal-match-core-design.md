# Project Animal Match Core Design

## 1. 방향

`Project Animal Match`는 Candy Crush Saga 계열의 검증된 스와이프 매치3 문법을 바탕으로, 사탕 대신 귀여운 동물 캐릭터와 구조 미션을 전면에 둔다. 플레이어는 동물 블록을 맞춰 구조 임무를 해결하고, 연쇄와 특수 블록으로 짧은 세션 안에서 큰 보상감을 얻는다.

## 2. Core Loop 분석

### 2.1 기본 루프

1. 스테이지 목표와 제한 이동 수를 확인한다.
2. 인접한 동물 블록을 스와이프한다.
3. 3개 이상 매치가 성립하면 블록이 제거된다.
4. 위 블록이 낙하하고 새 블록이 리필된다.
5. 자동 연쇄가 발생하면 콤보 점수와 게이지가 상승한다.
6. 목표를 달성하면 보상 화면으로 이동한다.
7. 실패하면 재도전, 부스터, 하트 사용, 보상형 광고 중 하나를 선택한다.

### 2.2 재미의 순환 구조

- 입력: 스와이프 한 번으로 즉시 결과가 나온다.
- 판단: 제한 이동 수 안에서 더 큰 매치와 특수 블록 생성을 노린다.
- 폭발: 매치, 연쇄, 특수 블록이 화면을 정리한다.
- 보상: 점수, 목표 진행도, 별, 동물 리액션, 피버 게이지가 상승한다.
- 재시도: 실패해도 다음 수가 보이는 구조로 다시 도전한다.

## 3. 특수 블록 설계

### 3.1 4매치: Line Runner

- 생성 조건: 가로 또는 세로 4개 일직선 매치
- 테마: 줄무늬 스카프를 두른 동물 블록
- 효과:
  - 가로 4매치: 해당 행 전체 제거
  - 세로 4매치: 해당 열 전체 제거
- 설계 의도: 초반부터 이해 가능한 가장 기본적인 큰 보상

### 3.2 L/T자 매치: Paw Bomb

- 생성 조건: L자 또는 T자 5개 이상 매치
- 테마: 발바닥 도장이 붙은 동물 블록
- 효과: 중심 기준 3x3 범위 제거
- 설계 의도: 장애물과 목표 블록이 밀집된 상황을 해결하는 도구

### 3.3 5매치: Rainbow Herd

- 생성 조건: 5개 이상 일직선 매치
- 테마: 무지개 목걸이를 단 리더 동물
- 효과: 교환한 동물 종류 전체 제거
- 설계 의도: 보드 전체를 바꾸는 최고 등급 보상

### 3.4 특수 블록 시너지

| 조합 | 효과 | 사용감 |
| --- | --- | --- |
| Line Runner + Line Runner | 행과 열을 십자 제거 | 넓은 정리감 |
| Line Runner + Paw Bomb | 3행 또는 3열 확장 제거 | 장애물 돌파 |
| Paw Bomb + Paw Bomb | 5x5 대폭발 | 중반 위기 해결 |
| Rainbow Herd + Line Runner | 선택 동물 다수를 Line Runner로 변환 후 발동 | 고점 콤보 |
| Rainbow Herd + Paw Bomb | 선택 동물 다수를 Paw Bomb으로 변환 후 발동 | 피버 직전 대역전 |
| Rainbow Herd + Rainbow Herd | 보드 전체 일반 블록 제거 | 최고 희귀 연출 |

## 4. 차별화 시스템

### 4.1 Zoo-Zoo Fever

- 매치, 연쇄, 특수 블록 발동으로 Fever Gauge가 상승한다.
- MVP 기준으로 게이지가 가득 차면 다음 `3회 플레이어 이동` 동안 `Zoo-Zoo Fever`가 발동한다.
- 8초 타이머는 VFX 연출 상한으로만 사용하고, 게임 규칙의 지속 시간은 턴 기준으로 계산한다.
- Fever 중에는 다음 보너스 중 하나를 적용한다.
  - 매치 점수 2배
  - 동물 목표 수집량 +1 보너스
- 매치 후 랜덤 1칸에 작은 발바닥 폭발은 밸런스 변동이 크므로 MVP 이후 후보로 둔다.
- 목적: 단순 제거보다 동물 구조가 빨라지는 감정적 보상 제공

### 4.2 동물 로스터 확장 원칙

동물 수는 수집감과 라이브 운영 여지를 위해 12종 이상으로 시작한다. 단, 매치3 보드에서 동시에 출현하는 동물 수가 많아지면 매치 확률이 급격히 낮아지므로 `전체 로스터`와 `스테이지별 출현 풀`을 분리한다.

- MVP 보드 로스터: 12종
- 글로벌 런칭 컬렉션 목표: 보드 12종 + 컬렉션/이벤트 예비 6종 = 18종
- 시즌 운영 확장 목표: 24종
- 한 스테이지 출현 풀: 5-6종
- 튜토리얼 구간 출현 풀: 4-5종
- 하드 레벨 출현 풀: 6종까지 허용
- 이벤트/수집 화면: 18종 컬렉션 로스터까지 노출 가능

### 4.3 동물별 구조 스킬과 표정 방향

동물 스킬은 캐릭터성을 살리되, 초반에는 자동/수동 복잡도를 낮춘다. 모든 동물은 최소 `기본`, `눈깜빡임`, `웃음`, `매치 성공`, `피버`, `걱정` 표정을 가진다.

MVP에서는 모든 동물이 동시에 스킬을 갖지 않는다. 스테이지별 `Rescue Buddy` 1종만 활성화하고, 해당 동물은 자동 1회 또는 제한된 조건에서만 도움을 준다.

| 동물 | 성격 | 스킬 | 대표 표정/애니메이션 |
| --- | --- | --- | --- |
| 토끼 | 빠르고 명랑함 | Fever 중 첫 매치 후 추가 리필 1회 | 긴 귀가 살짝 튀고 빠르게 눈깜빡임 |
| 고양이 | 영리하고 민첩함 | 목표 동물 근처 1칸 힌트 강조 | 눈웃음, 수염 흔들림 |
| 곰 | 든든하고 강함 | Paw Bomb 범위 +1 확률 | 천천히 웃고 코가 반짝임 |
| 병아리 | 작고 활발함 | 작은 콤보도 게이지 추가 획득 | 부리가 열리며 짧게 짹 웃음 |
| 개구리 | 튀어 오름 | 장애물 인접 매치 시 추가 피해 | 눈이 위아래로 튀는 blink |
| 여우 | 장난스럽고 똑똑함 | 실패 직전 추천 수 강조 | 한쪽 눈 찡긋, 얕은 미소 |
| 강아지 | 친근하고 충성스러움 | 클리어 직전 목표 수집량 +1 확률 | 혀를 살짝 내밀고 꼬리 배지 흔들림 |
| 판다 | 느긋하고 귀여움 | Fever 게이지 감소 지연 | 양눈을 천천히 감았다 뜸 |
| 돼지 | 낙천적이고 풍성함 | 코인 보상 소폭 증가 | 코가 통통 튀며 웃음 |
| 펭귄 | 차분하고 영리함 | 낙하 후 자동 연쇄 점수 보너스 | 몸을 좌우로 작게 흔듦 |
| 사자 | 용감하고 리더십 있음 | 하드 레벨 시작 부스터 확률 증가 | 갈기 glow와 자신감 있는 미소 |
| 코끼리 | 상징적이고 든든함 | 보스/피날레 레벨에서 장애물 피해 증가 | 큰 귀 펄럭임, 느린 눈깜빡임 |

### 4.4 FTUE와 메타 루프

- 첫 세션 목표는 `Level 5 클리어 + 첫 컬렉션 카드 해금 + 다음 동물 예고`다.
- Level 1-10에서는 하트 소모, 전면 광고, IAP 팝업을 금지한다.
- `Rescue Book`은 MVP 12종을 먼저 보여 주고, 글로벌 런칭에서는 컬렉션/이벤트 예비 동물 6종을 더해 18종까지 확장하는 상시 컬렉션 화면이다.
- 표정 애니메이션은 보드뿐 아니라 홈, 승리, 실패, 컬렉션, 이벤트 화면까지 확장한다.

| Level | 학습 목표 | 금지 수익화 | 세션 동기 |
| --- | --- | --- | --- |
| 1 | 첫 스와이프와 목표 칩 이해 | 실패 패널, 하트, 광고, IAP | 토끼 구조 성공감 |
| 2 | 복수 목표 진행감 | 광고, IAP | 곰 목표와 다음 특수 블록 예고 |
| 3 | 4매치 줄 제거 특수 블록 | 폭탄/무지개 강제 설명, 수익화 | Line Runner 학습 완료 |
| 4 | 첫 덤불과 Rescue Book 첫 카드 | 하트 소모, 판매 팝업 | 토끼 카드 해금 |
| 5 | 첫 세션 보상 묶음 | 전면 광고, 직접 IAP | 스타터 미션 1일차 보상 |
| 6 | 좁은 보드 판독 | 신규 시스템 2개 동시 설명 | 개구리 카드 예고 |
| 7 | 5매치/Rainbow 맛보기 | 피버 강제 설명, 수익화 | Rainbow Treat 체험 |
| 8 | Combo Gauge와 Fever 첫 경험 | 결제 제안 | Fever 기록 배지 |
| 9 | 이동 수 부족 감정 연출 | 하트 소모, 광고 | 무료 재도전 신뢰 확보 |
| 10 | 초반 밴드 마감 | 전면 광고, IAP | 다음 지역과 장기 목표 예고 |

## 5. 레벨 밸런싱 전략

### 5.1 초반 이탈 방지 구간

- Level 1-5: 실패 가능성을 낮추고 기본 스와이프, 목표 UI, 4매치를 학습시킨다.
- Level 6-10: 복수 목표와 첫 장애물을 도입하되 이동 수 여유를 둔다.
- Level 11-20: 특수 블록 조합을 자연스럽게 경험하도록 보드 배치를 설계한다.
- 원칙: 초반에는 결제/광고보다 이해와 성취감을 우선한다.

### 5.2 중반 난이도 상승 구간

- Level 21-60: 장애물, 좁은 보드, 복합 목표, 이동 수 압박을 순차적으로 섞는다.
- 실패율 목표: 일반 레벨 15-25%, 하드 레벨 35-45%
- 하드 레벨은 5-8개마다 1회 배치하고, 직전 레벨에서 필요한 특수 블록 조합을 학습시킨다.

### 5.3 유료화 결제 유도 구간

- 결제 유도는 불공정한 난수보다 `아깝게 실패한 상황`을 기반으로 한다.
- 실패 후 제안 순서:
  1. 무료 재도전
  2. 보상형 광고로 추가 이동 수
  3. 보유 부스터 사용
  4. 코인 구매 또는 번들 제안
- 유료 압박이 과하면 장기 유지율이 무너지므로, 소프트 런칭 지표로 실패율과 이탈률을 함께 본다.

## 6. 핵심 설계 원칙

- 한 수의 결과는 0.2초 안에 시각적으로 반응해야 한다.
- 특수 블록은 이름보다 모양과 발동 방향으로 이해되어야 한다.
- 동물 캐릭터는 단순 스킨이 아니라 목표, 리액션, 피버 보상에 연결되어야 한다.
- 레벨 실패는 억울함보다 `다음에는 깰 수 있겠다`는 판단을 남겨야 한다.
